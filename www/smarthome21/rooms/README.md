# Room photos

Drop room photos here. They get copied to `/config/www/smarthome21/rooms/`
on the HA box and are served at `/local/smarthome21/rooms/<file>`.

The dashboard expects these filenames (edit `dashboards/smarthome21.yaml` if
you change them):

- master-bedroom.jpg
- bedroom1.jpg
- bedroom2.jpg
- bedroom3.jpg
- pj-lounge.jpg
- lounge.jpg
- entertainment.jpg
- kitchen.jpg

Recommended: landscape JPGs, ~800x450 or larger, kept reasonably small so the
dashboard loads fast.
